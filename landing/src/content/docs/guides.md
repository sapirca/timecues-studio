Nine narrated walkthroughs cover TimeCues Studio end to end — from a first tour
to writing your own detector and self-hosting the stack. Each is a few minutes.
Read the one-line summary, then press play. For a short clip of every single
feature, see the [full feature walkthrough](/timecues/video-tour/).

Set a song up for annotation: confirm its tempo with the BPM chips, align the
